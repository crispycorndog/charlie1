App Name: Game Theft Auto
App Type: e-commerce
Problem it solves: Gamers need help finding discounts for games across different platforms.
Page 1: Home Page - Has all of the main stuff like top games, go straight to discounts on certain platforms, and stuff for accounts, etc.
Page 2: About Page - what the website does and a description of all the main stuff on the website
page 3: Games/store page - all discounted games sorted by genre, platform, etc.
page 4: Info page - shows the discount info for the game you choose like what's the discount, what it's like in different regions, etc.
page 5: Account Page - lets people make an account to get notifications on games they Wishlist if they go on sale
